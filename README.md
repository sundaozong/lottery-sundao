# 孙导带你夜夜笙歌

个人彩票观测站：开奖爬取 / 分析 / 娱乐预测 / 购彩记录 / 奖金估算 / 邮件推送。

> **合规声明**：号码预测与策略推荐**仅供娱乐**，不保证中奖，不构成任何投注建议。请理性购彩，量力而行。开奖请以官方公布为准。

## 技术栈

- 前端：Vue 3 + Vite + Vue Router（视觉对齐 lottery-ui v3 素净冷静）
- 后端：FastAPI + SQLAlchemy + SQLite
- 定时：APScheduler（启动时按设置间隔爬取）

ye-ye-sheng-ge/

## 启动

### 1. 后端

```bash
cd /workspace/ye-ye-sheng-ge
python3 -m venv backend/.venv
source backend/.venv/bin/activate
pip install -r backend/requirements.txt
# 可选：cp .env.example .env 并填写 SMTP
cd backend
uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload
```

健康检查：`http://127.0.0.1:8000/api/health`  
文档：`http://127.0.0.1:8000/docs`

### 2. 前端

```bash
cd /workspace/ye-ye-sheng-ge/frontend
npm install
npm run dev
```

浏览器打开 Vite 提示的地址（默认 `http://127.0.0.1:5173`）。`/api` 已代理到后端 `8000`。

## 功能清单

| 功能 | 状态 | 说明 |
|------|------|------|
| 开奖列表 / 最新 | ✅ | SQLite 存储；首次自动种子数据 |
| 手动 / 定时爬取 | ✅ | 福彩部分公开接口尽力而为；失败保留种子并返回错误列表 |
| 号码分析 | ✅ | 冷热频次、遗漏、热力 |
| 开奖回声 | ✅ | 对照近期开奖，找出与一注号码重合最多的期次；数字彩按位比较。仅供娱乐，不代表下期结果 |
| 号码结伴 | ✅ | 主号共现：哪些号码经常一起出现；数字彩看不同位置。仅供娱乐，不构成投注建议 |
| 号码撞车 | ✅ | 同一彩种多注对照：撞号浪费与没覆盖到的号；数字彩按位比较。可一键用购彩记录。预测/分析仅供娱乐，不构成投注建议 |
| 重号脉搏 | ✅ | 相邻两期主号有多少留下来，再把一注对照最新开奖。乐透按集合，数字彩按位；特别号单独计。仅供娱乐，不构成投注建议 |
| 冷热动量 | ✅ | 短窗口出现率减去长窗口出现率，看号码在升温还是降温。乐透按集合，数字彩按位；特别号单独计。仅供娱乐，不构成投注建议 |
| 邻号牵引 | ✅ | 主号开出后，看 ±1 邻号在随后几期是否更常出现。这是跨期邻号，不是同期结伴，也不是原号重开。乐透按集合并单独计特别号；数字彩按位，0 与 9 不环绕。仅供娱乐，不构成投注建议 |
| 跨度脉动 | ✅ | 主号跨度（最大减最小）的历史分布，加上短窗平均相对长窗平均是变宽还是变窄，并可给一注打分。乐透按集合，特别号不计入，多个特别号另计；数字彩按整注各位，0 与 9 不绕圈。仅供娱乐，不构成投注建议 |
| 和值脉动 | ✅ | 主号和值（各号相加）的历史分布，加上短窗平均相对长窗平均是走高还是走低，并可给一注打分。乐透按集合，特别号不计入，多个特别号另计；数字彩按整注各位，0 与 9 不绕圈。和号码形态里的静态和值分开。仅供娱乐，不构成投注建议 |
| 奇偶脉动 | ✅ | 主号奇数个数的历史分布，加上短窗平均相对长窗平均是走高还是走低，并可给一注打分。乐透按集合，特别号不计入，多个特别号另计；数字彩按整注各位，0 是偶数、9 是奇数，不绕圈。和号码形态里的静态奇偶比分开。仅供娱乐，不构成投注建议 |
| 质合脉动 | ✅ | 主号质数个数的历史分布，加上短窗平均相对长窗平均是走高还是走低，并可给一注打分。乐透按集合，1 视为质数，特别号不计入，多个特别号另计；数字彩按整注各位，1、2、3、5、7 为质，0 与其余非质为合。和号码形态里的静态奇偶、以及只看奇数个数的奇偶脉动分开。仅供娱乐，不构成投注建议 |
| 区位脉动 | ✅ | 主号按数值区间分成三区，看个数配比和区位偏度（最多一区减去最少一区），加上短窗平均相对长窗平均是更偏还是更匀，并可给一注打分，等权纳入脉动综合。乐透按集合均分区间，特别号不计入、有特别号时按自己的区间另计；数字彩按 0–3 / 4–6 / 7–9。和 012 路、跨度、奇偶、质合，以及号码形态里的静态分区比分开。仅供娱乐，不构成投注建议 |
| 尾数脉动 | ✅ | 主号不重复个位的种类数，加上短窗平均相对长窗平均是更散还是更集中，并可给一注打分，等权纳入脉动综合。乐透取每位主号的个位，同一尾数只算一种；数字彩各位本身就是尾数，0 与 9 不绕圈。特别号单独统计、不并进主号。和 012 路、区位、跨度、和值分开。仅供娱乐，不构成投注建议 |
| AC值脉动 | ✅ | 主号算术复杂度的历史分布，加上短窗平均相对长窗平均是走高还是走低，并可给一注打分，等权纳入脉动综合。两两绝对差的不重复个数减去号码个数减一；少于两个号的那期跳过，不记成 0。乐透按去重后的主号，数字彩按整注各位，0 与 9 不绕圈。特别号单独统计、不并进主号。和跨度、连号簇、012 路、区位、尾数分开。仅供娱乐，不构成投注建议 |
| 和尾脉动 | ✅ | 主号和值个位（各位相加后对 10 取余）的历史分布，加上短窗平均相对长窗平均是走高还是走低，并可给一注打分，等权纳入脉动综合。乐透按去重后的主号求和取个位；数字彩按整注各位，重复保留，0 与 9 不绕圈。特别号不并进主号，有特别号时另算。和原始和值、尾数种类，以及竞品静态和值尾表分开。仅供娱乐，不构成投注建议 |
| 预测推荐 | ✅ | hot/cold/hybrid/random；API 与页面均有娱乐免责 |

## 彩种

双色球 `ssq`、大乐透 `dlt`、福彩3D `fc3d`、排列三 `pl3`、排列五 `pl5`、七星彩 `qxc`、快乐八 `kl8`

## 已知限制

1. **爬虫**：仅对福利彩票官网部分 JSON 接口做尝试；大乐透/排三/排五/七星彩等无稳定公开源时**只用种子数据**，并在爬取结果里提示。接口变更或网络拦截会导致爬取失败，属预期。
2. **邮件**：必须自行配置 SMTP；本环境默认不发送真实邮件。
3. **奖金**：一等奖等浮动奖为示意金额；快乐八按「选十」简化表。
4. **定时间隔**：修改设置中的分钟数后，需重启 uvicorn 才能让 APScheduler 重读间隔。
5. **数据标签**：顶栏「示例 / 混合 / 爬取」反映本地 `source` 字段，非实时官方状态。
